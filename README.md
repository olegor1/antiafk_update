## О проекте

**Rust Anti-AFK** — утилита для автоматического предотвращения кика с сервера Rust за неактивность. Программа периодически симулирует прыжок игрока и при необходимости автоматически переподключается к серверу после кика.

---

## Возможности

| Функция | Описание |
|---|---|
| **Авто-прыжок** | Периодически нажимает клавишу прыжка с настраиваемым интервалом |
| **Авто-реконнект** | Автоматически переподключается к серверу при кике |
| **Случайный разброс** | Интервал ±5 сек для менее предсказуемого поведения |
| **Только активное окно** | Работает только когда Rust в фокусе |
| **Горячие клавиши** | Быстрое включение/выключение без открытия GUI |
| **Тёмный GUI** | Удобный интерфейс в тёмном стиле |
| **Сохранение настроек** | Все параметры сохраняются между запусками |

## Требования

- **Windows** 10 / 11
- **[AutoHotkey v2.0](https://www.autohotkey.com/download/)** — обязательно версия 2.x

---

## Установка и запуск

```
1. Скачайте и установите AutoHotkey v2.0
2. Скачайте AntiAHK.ahk из этого репозитория
3. Дважды кликните на AntiAHK.ahk для запуска
```

> При первом запуске автоматически создаётся файл `antiafk_settings.ini` с настройками по умолчанию.

## Настройки

### Параметры сервера

| Параметр | По умолчанию | Описание |
|---|---|---|
| IP сервера | `185.1.2.3` | IP-адрес сервера Rust |
| Порт | `28015` | Порт сервера |

### Таймеры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Прыжок (сек) | `55` | Интервал между автоматическими прыжками |
| Проверка кика (сек) | `10` | Интервал проверки и попытки реконнекта |

### Горячие клавиши

| Действие | По умолчанию | Описание |
|---|---|---|
| Включить AFK | `F9` | Запустить Anti-AFK |
| Выключить AFK | `F10` | Остановить Anti-AFK |
| Клавиша прыжка | `Space` | Клавиша, которая нажимается для прыжка |
| Консоль Rust | `F1` | Клавиша открытия консоли в Rust |

### Опции

| Опция | По умолчанию | Описание |
|---|---|---|
| Автореконнект при кике | ✅ включено | Автоматически переподключаться при кике |
| Только в активном окне | ✅ включено | Работать только когда Rust в фокусе |
| Случайный разброс ±5 сек | ❌ выключено | Добавить случайность к интервалу прыжка |

## Использование

1. **Запустите** `AntiAHK.ahk`
2. **Укажите** IP и порт вашего сервера
3. **Настройте** интервалы и опции по вкусу
4. **Нажмите** `▶ ВКЛЮЧИТЬ` или используйте горячую клавишу `F9`
5. **Статус** изменится на `АКТИВЕН ✓` (зелёный цвет)

Для остановки нажмите `■ ВЫКЛЮЧИТЬ` или `F10`.

## Как работает авто-реконнект

Когда включён **Автореконнект**, скрипт с заданным интервалом:
1. Проверяет, существует ли окно Rust
2. Открывает консоль (`F1` по умолчанию)
3. Вводит команду `connect IP:PORT`
4. Отправляет Enter и закрывает консоль

Если вы уже в игре — подключение к тому же серверу просто обновится без разрыва. Если вас кикнули — вы автоматически переподключитесь.
